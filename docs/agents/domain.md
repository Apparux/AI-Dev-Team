# Domain Docs

本项目采用 single-context 领域文档布局，路径均相对于项目根目录。

## 探索前读取

- `GLOSSARY.md`：领域术语及其定义。
- `docs/adr/`：只读取与当前工作相关的架构决策记录。

文件或目录尚不存在时，静默继续，无需报告缺失或建议预先创建。
术语或决策明确后，由 `/domain-modeling` 按需创建。

## 使用统一术语

在工单标题、设计建议、假设和测试名称中提及领域概念时，使用词汇表中的术语，避免使用词汇表明确排除的同义词。

需要的概念尚未收录时，先判断是否误用了项目之外的术语；确有缺口时，标记为 `/domain-modeling` 的后续输入。

## 显式指出 ADR 冲突

建议与现有 ADR 冲突时，注明对应 ADR 及重新讨论的理由，而不是静默覆盖。
