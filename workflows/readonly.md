# 单次只读核查

阶段：确认范围 → 解析配置 → 读取职责与方法 → 派发只读核查 → 核对结果。

“只读”是本工作流的业务行为范围，不是新会话的原生权限模式。最高权限默认见 `DESIGN.md` 2.4；不能据此扩大读取/写入范围，或声称具备只读沙箱。

进入条件：项目已登记；目标、读取范围和验收文件已获用户确认；必需 Skill/支持文件可读；原生权限模式没有被当作业务授权。

核对门禁：结果必须包含实际输入文件的内容依据、方法支持文件标识、已读资产及未执行的验证。主管对照源文件检查，不能用 idle/done 或员工 PASS 代替核对。

输出仅为“只读观察已核对”或“BLOCKED”。正式 Task/Attempt 身份、业务完成状态及运行中规则变化处理不在此工作流内。
